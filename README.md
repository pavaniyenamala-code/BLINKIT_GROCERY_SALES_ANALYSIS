# BlinkIT Grocery Sales Analysis

## Project Overview
Analyzed BlinkIT grocery sales data using Excel to understand sales performance, product categories, and outlet performance.

## Tools Used
- Microsoft Excel / WPS Spreadsheet
- Pivot Tables
- Pivot Charts
- Excel Formulas

## Project Objectives
1. Overall Sales Performance
2. Product Category and Sales Comparison
3. Outlet Performance and Sales Relationships
4. Statistical Analysis of Sales

## Key Findings
- Total Sales: ₹12,01,681.49
- Average Sales: ₹140.99
- Maximum Sales: ₹266.89
- Minimum Sales: ₹31.29
- Top four product categories contribute approximately 50.60% of total sales.

## Conclusion
This project provides insights into product and outlet sales performance to support better business decisions.
